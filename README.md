# NexTrade 🚀  
**A Modern C2C Marketplace for Smart Trading**

---

## 🌟 About NexTrade
**NexTrade** is a high-performance, full-stack **Consumer-to-Consumer (C2C)** marketplace built to make buying and selling pre-owned goods simple, secure, and fast. Inspired by platforms like OLX, NexTrade delivers a smooth user experience with real-time communication, advanced search, and a clean, responsive interface.

The platform empowers users to turn physical goods into digital listings, manage their own storefront, and negotiate deals instantly — all in one place.

---

## ✨ Features at a Glance

### 🔐 Authentication & Security
- Secure user authentication using **JWT**
- Protected routes for authorized access
- Safe session handling

### 📦 Product Listings & Management
- Create, edit, and delete product listings (CRUD)
- Upload and manage product images via **Cloudinary**
- Add price, condition, category, and description

### 🔎 Smart Search & Filtering
- Keyword-based product search
- Filter by:
  - Category
  - Price range
  - Item condition

### 💬 Real-time Chat
- Built-in messaging system
- Instant buyer–seller communication
- Smooth negotiation experience

### 👤 User Dashboard
- Centralized profile management
- View and manage active listings
- Update personal account settings
